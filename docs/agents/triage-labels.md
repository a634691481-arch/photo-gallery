# Triage labels

The five canonical triage roles, one label per role. Label strings equal role names.

| Role                                                    | Label             |
| ------------------------------------------------------- | ----------------- |
| Incoming work awaiting initial assessment               | `needs-triage`    |
| Needs more info from the reporter before it can proceed | `needs-info`      |
| Specified and ready for an agent to implement           | `ready-for-agent` |
| Needs a human's judgement or action                     | `ready-for-human` |
| Not going to be addressed                               | `wontfix`         |

Apply these labels to issues as they move through triage. If the tracker already has labels with different names that map to these roles, update this table instead of creating duplicates.
